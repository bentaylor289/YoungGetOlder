# YoungGetOlder
Code to reproduce figures from "Young Get Older, but Old Get Younger: Warming-Induced Circulation Change Explains Contrasting Pattern of Projected Pacific Deoxygenation". 

Using the .nc files stored at the UC San Diego library (https://doi.org/10.6075/J0KK9CRD), you should be able to reproduce the Figs 1-2 and 3-10 of the manuscript. Use the codes labeled "cleaned" and Mean_Budget_fromnc.ipynb (which calls O2age_budget_ncfiles.py).
